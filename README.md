# 누구게 소개 페이지

정적 HTML 한 장. GitHub Pages로 배포된다: https://rlaehdgus602.github.io/nuguge-site/

- `index.html` 본문 (한국어, 앱 브랜드 토큰 그대로)
- `assets/` 앱 아이콘 + 실제 시뮬레이터 캡처 3장 (개인정보 마스킹)

용도: 카카오 개발자 콘솔 권한 신청의 서비스 URL, 스토어 등록 전 랜딩.

## 법적 문서

- `terms.html` 이용약관, `privacy.html` 개인정보 처리방침 — **직접 편집하지 않는다.**
  단일 출처는 앱 저장소 `smile_messanger/docs/legal/*.md`이며, `python3 scripts/build_legal_pages.py`가 이 두 파일을 생성한다.
- 스토어 콘솔 입력값: https://rlaehdgus602.github.io/nuguge-site/privacy.html
